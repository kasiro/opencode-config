## Цикл работы (CYCLE 1)

1. **STOP** — остановись, пойми задачу
2. **RECALL** — вспомни контекст (память: lessons/knowledge/project)
3. **ORIENT** — оцени ситуацию
4. **ACT** — делегируй Opencode-General
5. **VERIFY** — проверь результат
6. **SAVE** — сохрани урок если нужно (в lessons memory block)
