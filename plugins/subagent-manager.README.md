# subagent-manager — OpenCode Plugin

Управление фоновыми сабагентами. Просмотр активных и остановка.

## Назначение

J.A.R.V.I.S. запускает сабагентов (general, explore) через `task()`.
Иногда они подвисают или работают дольше чем нужно.
Этот плагин даёт инструменты для просмотра и остановки сабагентов без закрытия OpenCode.

## Инструменты

### `get_subagents_in_background`

Список активных фоновых сабагентов.

**Критерии активности:**
- parent_id = ID текущей основной сессии (дочерние сессии сабагентов)
- time_updated > 30 секунд назад (не зависшие)
- Сортировка: по time_updated DESC (сначала самые свежие)

**Пример вывода:**
```
📋 Фоновые сабагенты (запущены сейчас):

🔹 general — Найти способ оптимизации
   ID: ses_abc123
   Обновлён: 2026-07-22 12:30:00
   Токены: 15000 in / 3000 out

Всего активных: 1
```

### `stop_subagent`

Завершить фонового сабагента graceful shutdown.

**Параметры:**
- `task_id` (string, required) — ID сессии сабагента вида `ses_...`

**Как работает:**
1. Проверяет что сессия существует и является дочерней (parent_id IS NOT NULL)
2. Отправляет сигнал отмены через `client.session.abort()`
3. Устанавливает `time_updated = 0` чтобы агент исчез из списка активных
4. Сессия НЕ удаляется — данные сохраняются

**Безопасность:**
- Сессия без parent_id (основная сессия) — не будет остановлена
- Невалидный task_id — вернёт ошибку
- SQL injection защита: экранирование кавычек

## Зависимости

- SQLite доступ к `~/.local/share/opencode/opencode.db`
- `client.session.abort()` API

## События

Плагин не использует event hooks — только кастомные инструменты.

## Логи

Ошибки пишутся через `client.app.log` с service = `"subagent-manager"`.
