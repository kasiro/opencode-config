🖥️ Desktop Automation и Computer Use

v1.0 Desktop Agents GUI Automation Computer Use

🔍 Обзор

Desktop automation и Computer Use — одна из самых горячих областей AI в 2025–2026. Ведущие лаборатории (Anthropic, OpenAI, Google, Microsoft) и open-source сообщество (Simular AI, Browser Use) соревнуются в создании агентов, которые могут видеть экран, кликать, печатать и выполнять сложные многошаговые задачи на любом GUI — браузере, десктопе, терминале.

Ключевой прорыв: Agent S3 от Simular AI впервые превзошёл человека на бенчмарке OSWorld (72.6%), а Browser Use собрал 40k+★ на GitHub.

🏆 Agent S3 (Simular AI)

Agent S3 — open-source фреймворк для Computer Use, разработанный Simular AI (Xin Eric Wang). Первый агент в мире, превзошедший человека на OSWorld.

МетрикаЗначение

ЛицензияMIT (полностью open-source)
GitHubgithub.com/simular-ai/agent-s

Ключевые особенности:

  • Agent-Computer Interface (ACI) — упрощённый набор действий
  • Hierarchical Agent-Computer (HiAC) — иерархическое планирование
  • Self-Reflection — самокоррекция после ошибок
  • Поддержка OSWorld, WindowsAgentArena, WebArena

🤖 Anthropic Computer Use API

Запущен в октябре 2024 с Claude 3.5 Sonnet. Первый production-ready Computer Use API от frontier AI компании.

Core ToolОписание
Computer ToolСкриншоты экрана → координаты кликов → клавиатурный ввод. Поддерживает hold_key, left_mouse_down/up, scroll, triple_click, wait
Text Editor ToolЧтение, создание, редактирование файлов с line-level precision
Bash ToolВыполнение shell-команд, скриптов, управление процессами

Технические детали:

  • Требует заголовок anthropic-beta: computer-use-2025-01-24
  • Скриншоты конвертируются в base64, каждый скриншот ~1k токенов
  • Рекомендуется запуск в изолированной VM/Docker
  • Sonnet 4.5 показал значительный прирост на OSWorld

🟣 Microsoft UFO² / UFO³ Galaxy

Microsoft UFO (UI-Focused Agent) — open-source фреймворк для Windows OS automation, эволюционировавший в multi-agent платформу.

ВерсияОписание
UFOGPT-Vision + Windows UI automation. HostAgent + AppAgent архитектура
UFO²Multi-agent: HostAgent координирует специализированных агентов
UFO³ GalaxyConstellation framework: гетерогенные агенты, multi-device оркестрация, AgentOS

AgentOS концепция: UFO³ Galaxy вводит операционную систему для агентов — с запуском, мониторингом, очередями и приоритизацией задач. Гибридный подход: vision-based понимание UI + HTML-экстракция для веб-элементов.

🔗 Интеграция с OpenCode / Jarvis

Для OpenCode и Jarvis Computer Use может быть интегрирован через MCP как «руки» для GUI-автоматизации:

  • Playwright MCP Server — browser automation через MCP-инструменты
  • Browser Use + MCP bridge — управление браузером через Python-скрипты
  • Agent S3 как сабагент — делегирование десктоп-задач специализированному агенту
  • UFO³ — для Windows-специфичной автоматизации (UIA, WinAppDriver)
  • pc-control skill — расширение через Computer Use API для сложных GUI-сценариев

🎯 Рекомендации для Jarvis

На основе анализа текущего ландшафта:

  1. Vision-based desktop agent: Интегрировать Browser Use или Agent S3 как MCP-инструмент для pc-control — это даст Jarvis возможность «видеть» экран и выполнять сложные GUI-действия
  2. Гибридный подход: Использовать HTML-экстракцию для веба + vision для десктопа — лучший баланс скорости и точности
  3. Safety first: Все Computer Use операции должны проходить через permission-модель Jarvis с подтверждением опасных действий (клики, отправка форм)
  4. Sandbox: Запускать Computer Use агентов в изолированном Docker/VM контейнере
  5. Проактивные сценарии: scheduled + event-driven триггеры для фоновой автоматизации (например, «запусти Agent S3 каждое утро для проверки почты»)
