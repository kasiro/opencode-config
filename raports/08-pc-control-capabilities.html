Архитектурное улучшение: MCP сервер pc-control

Текущий подход: OpenCode → subprocess → python3 script.py. Медленно, нет единого API.

Предложение: MCP сервер pc-control с 12+ инструментами.

{
  "mcpServers": {
    "pc-control": {
      "command": "python3",
      "args": ["~/.config/opencode/mcp/pc_control_server.py"]
    }
  }
}

# Инструменты MCP pc-control:
# 
# 🪟 Окна:
#   window_minimize_all() → void
#   window_focus(wm_class: str) → void
#   window_switch_workspace(number: int) → void
#   window_get_list() → Window[]
#
# 🚀 Приложения:
#   app_launch(name: str, wm_class: str, workspace: int) → void
#   app_close(wm_class: str) → void
#   app_is_running(wm_class: str) → bool
#
# 🎮 Клавиатура:
#   keyboard_press(key: str) → void  
#   keyboard_type(text: str) → void
#   keyboard_tab(count: int) → void
#
# 🔐 Система:
#   system_screenshot() → str (path)
#   system_notify(title: str, message: str) → void
#   system_sleep() → void
#   system_clipboard_get() → str
#   system_clipboard_set(text: str) → void
#
# 👶 Режимы:
#   mode_set(mode: str) → void
#   mode_get() → str
#
# 🔌 VPN:
#   vpn_connect() → void
#   vpn_disconnect() → void
#   vpn_status() → str

Преимущества MCP подхода:

  • Один процесс, единое состояние (через EventBus)
  • Быстрее — нет накладных расходов на subprocess каждый раз
  • Типизированные аргументы и возвраты через MCP протокол
  • Возможность композиции: несколько инструментов в одном запросе
  • Автоматическая документация (list_tools)

Как скрипты взаимодействуют с OpenCode

┌─────────────────────────────────────────────────────────────────┐ │ OpenCode (LLM + Tools) │ │ │ │ Пользователь: "открой калькулятор" │ │ │ │ │ ▼ │ │ SKILL.md: pc-control активируется │ │ │ │ │ ▼ │ │ Формируется команда: │ │ python3 ~/.config/opencode/skills/pc-control/scripts/calc_on.py│ │ │ │ │ ▼ │ │ subprocess.run([...]) → скрипт выполняется │ │ │ │ │ ▼ │ │ Результат: stdout/returncode → OpenCode → ответ пользователю │ └─────────────────────────────────────────────────────────────────┘ # Время выполнения: ~200-500ms на subprocess + Python import # MCP версия: ~5-10ms на инструмент (одна Python сессия)
