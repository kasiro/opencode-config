📖 Что такое Autolearn

Autolearn — это явная, протоколированная система извлечения и сохранения уроков в OpenCode/J.A.R.V.I.S. В отличие от "чёрного ящика", где обучение происходит невидимо, autolearn работает через явные вызовы инструментов с указанием контекста, уверенности и типа урока.

Механизм встроен в agentmemory как часть 4-tier консолидации на уровне Procedural Memory — самой абстрактной и долговременной формы памяти.

📂 Хранилище уроков

Извлечённые уроки хранятся в ~/.config/opencode/global-rules.md в секции [AUTOLEARN LESSONS]:

---
[AUTOLEARN LESSONS] ═══════════════════════════════════════
# Извлечённые уроки autolearn — сохранено 23.06.2026
═══════════════════════════════════════════════════════════

## Research и ответы
- При нумерованных вопросах от сэра не уходить в исследовательский цикл.
  Собрать данные из 2-3 параллельных источников и сразу выдать структурированный ответ.
- Research-before-conclusions: всегда искать в интернете перед тем как делать
  утверждения, аудиты, оценки или выводы.

## Выполнение инструкций
- Когда сэр даёт точные команды bullet-списком с конкретными флагами/аргументами —
  выполнять их напрямую, не делегируя сабагентам и не анализируя дальше.

## Дебаг и диагностика
- При отладке API/совместимости — сначала эмпирическая проверка (curl, прямой
  запрос), потом выводы. Не полагаться только на трассировку кода.

## MCP и инструменты
- При удалении MCP серверов — чистить и opencode.json, и глобально.
  Не оставлять осиротевшие пакеты.

На текущий момент зафиксировано 7 извлечённых уроков в 4 категориях.

🏷️ Система тегов

ТегНазначениеПример
error Ошибка, которую нужно запомнить и не повторять lesson_save(confidence=0.7, tags="error", content="glob медленнее fd в 5-10x")
pattern Рабочий паттерн, который нужно повторять lesson_save(confidence=0.5, tags="pattern", content="Для поиска файлов — fd вместо find")

correction Исправление неверного понимания lesson_save(confidence=0.7, tags="correction", content="Сэр использует doas, не sudo")
execution Оптимизация выполнения команд/процессов lesson_save(confidence=0.6, tags="execution", content="bun вместо npm — в 10x быстрее")

📊 Confidence Scoring

УровеньЗначениеКогда ставить
1.0КритическийБезопасность, потеря данных, архитектурные решения
0.8PreferenceПредпочтения пользователя, confirmed паттерны
0.7ErrorПодтверждённая ошибка (воспроизведена 2+ раза)
0.5PatternРабочий паттерн, замеченный 1-2 раза
0.3ШумСомнительное наблюдение, единичный случай

Правило: уроки с confidence < 0.3 автоматически считаются шумом и не участвуют в recall.

🔄 Auto-trigger Self-improvement

При сохранении урока с тегом tags="error" срабатывает механизм авто-улучшения:

  1. Детекция: CYCLE 1 → VERIFY обнаруживает lesson_save(tags="error")
  2. Анализ: Агент анализирует причину ошибки и контекст
  3. Действие:
    • Если ошибка повторяется 2+ раза → обновление SKILL.md
    • Если ошибка в конфигурации → исправление opencode.json
    • Если ошибка в подходе → запись урока с correction
  4. Фиксация: git commit изменений скилла/конфига

Важно: Сэр тоже может ошибаться. Агент учитывает контекст и не записывает уроки вслепую.

🔍 Accuracy Protocol

Система включает встроенный Accuracy Protocol — механизм проверки достоверности:

  • Research-before-conclusions: всегда искать в интернете перед утверждениями
  • Скептицизм к себе: не полагаться только на трассировку кода если есть сомнения
  • Double-check: прямые доказательства от сэра (вывод команд, логи) авторитетнее моментальных снимков
  • Эмпирика важнее анализа: при отладке API — сначала curl, потом выводы

📎 Повторная ошибка → git commit

Правило: Если одна и та же ошибка зафиксирована 2+ раза:

1. lesson_recall(query="error", tags="error") → обнаружить повторение
2. Проанализировать контекст обеих ошибок
3. Обновить SKILL.md с инструкцией по предотвращению
4. git commit -m "fix: add prevention for [ошибка]"

Это превращает единичные ошибки в системные улучшения, доступные всем агентам.

🎯 Как работает lesson_recall

Поиск уроков использует комбинацию: семантический поиск + фильтрация по тегам + порог confidence:

agentmemory_memory_lesson_recall(query="поиск файлов", limit=5, minConfidence=0.3)
ПараметрНазначениеРекомендация
queryПоисковый запрос (семантика)Ключевые слова по теме
limitКоличество результатов5 (оптимально для контекста)
minConfidenceМинимальный порог уверенности0.3 (отсеивает шум)
projectФильтр по проектуУказывать для scoping

Механизм: При lesson_recall() уроки ранжируются по confidence (высший — первый). Уроки с confidence < minConfidence отбрасываются. Дублирующееся содержимое авто-усиливает существующий урок (confidence повышается).
