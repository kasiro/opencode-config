1. Что такое MCP

Model Context Protocol (MCP) — открытый протокол, стандартизирующий взаимодействие между LLM-агентами и внешними инструментами/данными. Разработан Anthropic, передан Linux Foundation в декабре 2025.

Базовые принципы:

  • Транспорт: stdio (локальные процессы) или SSE (удалённые серверы)
  • Формат: JSON-RPC 2.0 (request/response/notification)
  • Три примитива: Tools, Resources, Prompts
  • Безопасность: изолированные процессы, sandbox по умолчанию
  • Стандартизация: единый интерфейс для всех LLM-клиентов
ПримитивОписаниеПример
ToolsФункции, которые может вызывать LLMget_weather(city), search_files(query)
ResourcesДанные, которые может читать LLMfile:///logs/app.log, db://schema
PromptsГотовые шаблоны промптовanalyze_logs, code_review

5. MCP Security: OWASP Top 10

OWASP опубликовал MCP Top 10 — категории уязвимостей, специфичных для MCP архитектуры:

#УязвимостьОписание
MCP-1Tool InjectionЗлонамеренные аргументы в tool calls
MCP-2Resource LeakageНеавторизованный доступ к ресурсам
MCP-3Prompt InjectionВнедрение инструкций через user input
MCP-4Cross-MCP ScriptingМеж-серверные атаки
MCP-5Data ExfiltrationКража данных через MCP ответы
MCP-6Tool ConfusionПровокация вызова опасного tool
MCP-7Session HijackingПерехват SSE сессий
MCP-8Unvalidated InputОтсутствие валидации параметров
MCP-9Resource ExhaustionDoS через ресурсоёмкие операции
MCP-10Insecure TransportНезащищённые stdio/SSE каналы

Рекомендация: при разработке MCP-серверов следовать OWASP MCP Top 10. Использовать sandboxing для изоляции серверов, input validation для всех tool параметров, rate limiting для предотвращения resource exhaustion.

6. Transfer в Linux Foundation

В декабре 2025 Anthropic передал спецификацию MCP в Linux Foundation. Это ключевой момент для экосистемы:

  • Вендор-нейтральность: протокол не привязан к Anthropic/Claude
  • Open Governance: управление через открытый комитет
  • Enterprise adoption: крупные компании (Microsoft, Google, Meta) участвуют в развитии
  • Стандартизация: MCP движется к статусу industry standard для AI-tool integration

После передачи темп развития ускорился: за Q1 2026 количество серверов выросло на 200%, появились MCP Gateways, MCP Firewalls, managed MCP hosting.

7. Применимость к OpenCode

OpenCode уже поддерживает MCP — это основной механизм расширения функциональности. Каждый MCP сервер добавляется в opencode.json:

{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "."]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_TOKEN": "${GITHUB_TOKEN}" }
    }
  }
}

8. Рекомендации

  1. MCP Gateway: создать легковесный gateway для роутинга запросов между MCP серверами. Gateway обеспечивает единую точку входа, rate limiting, authentication и логирование всех MCP вызовов.
  2. Jarvis MCP Bundle: разработать и опубликовать набор MCP серверов для Jarvis (voice, pc-control, knowledge, orchestrator). Упаковать как npm-пакет @jarvis/mcp-bundle.
  3. MCP Health Dashboard: интегрировать Sentry или Prometheus для отслеживания состояния всех MCP серверов: latency, error rate, uptime.
  4. Security Audit: провести аудит текущих MCP серверов на соответствие OWASP MCP Top 10. Особое внимание — sandboxing и input validation.
  5. SSE Support: рассмотреть переход части MCP серверов на SSE транспорт для удалённого доступа (например, Jarvis на сервере → OpenCode на ноутбуке).
