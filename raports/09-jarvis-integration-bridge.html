Отчёт 9: Интеграция OpenCode + Jarvis через bridge

Дата: Июль 2026 | Статус: Проектирование

Зачем нужен bridge

OpenCodeJarvis (pc-control)
Язык TypeScript / Go Python + Rust (core)
Умеет LLM, интернет, код, память, MCP, агенты Микрофон, wake-word, VAD, управление ПК, режимы
Не умеет Микрофон, wake-word, VAD, GNOME D-Bus LLM, интернет, код, долговременная память
Сильная сторона Мозг: понимание, генерация, планирование Тело: действия, сенсоры, периферия

Вывод: OpenCode — мозг, Jarvis — тело. Вместе — полноценный ассистент.

Три способа интеграции

1. Python executor → subprocess (прямой запуск) Работает сейчас

OpenCode вызывает Python скрипты pc-control через subprocess. Используется в SKILL.md.

# OpenCode → subprocess → python3 script.py
# Плюсы: работает прямо сейчас, не требует изменений
# Минусы: ~200-500ms на каждый вызов, нет состояния между вызовами,
#         нет двусторонней связи, нет сложных возвратов

def execute_command(script_path: str, args: list = None) -> dict:
    cmd = ["python3", script_path] + (args or [])
    result = subprocess.run(cmd, capture_output=True, text=True)
    return {
        "stdout": result.stdout,
        "stderr": result.stderr,
        "returncode": result.returncode
    }

# Пример:
# execute_command("~/.config/opencode/skills/pc-control/scripts/screenshot.py")
# → {"stdout": "/tmp/screenshot_20260701_1234.png", "returncode": 0}

2. JSON-RPC через jarvis_server.py Прототип

Эмуляция Rust-core Jarvis. Python HTTP сервер, который принимает JSON-RPC запросы.

# ~/.config/opencode/mcp/jarvis_server.py
# Запускается как MCP сервер

{
  "mcpServers": {
    "jarvis": {
      "command": "python3",
      "args": ["~/.config/opencode/mcp/jarvis_server.py"]
    }
  }
}

3. WebSocket IPC Предложение

Самый производительный способ. WebSocket сервер на порту 127.0.0.1:9712.

# WebSocket IPC протокол:
# ws://127.0.0.1:9712
# 
# Сообщения (JSON):
# { "type": "request", "id": "1", "method": "app.launch", 
#   "params": {"name": "brave", "workspace": 1} }
#
# { "type": "response", "id": "1", "result": {"success": true} }
#
# { "type": "event", "event": "state:mode_changed", 
#   "data": {"old": "kid", "new": "dev"} }
#
# { "type": "ping" } / { "type": "pong" }

# Плюсы WebSocket:
# - Двусторонняя связь (OpenCode может получать события от Jarvis)
# - Persistent connection (нет overhead на handshake)
# - Event push (Jarvis сам сообщает об изменениях)
# - Быстрее HTTP (меньше заголовков)

Bridge-слой: opencode_jarvis_bridge.py

# ~/.config/opencode/mcp/opencode_jarvis_bridge.py
# 
# Единый bridge-слой для всех трёх способов интеграции.
# Позволяет OpenCode взаимодействовать с Jarvis через:

class OpenCodeJarvisBridge:
    """Мост между OpenCode (MCP) и Jarvis (pc-control)"""
    
    def __init__(self, mode: str = "direct"):
        # mode: "direct" | "rpc" | "ws"
        self.mode = mode
        self.ws_connection = None
    
    async def direct_call(self, script: str, **kwargs) -> dict:
        """Прямой вызов Python скрипта (subprocess)"""
        cmd = ["python3", f"~/.config/opencode/skills/pc-control/scripts/{script}"]
        for k, v in kwargs.items():
            cmd.extend([f"--{k}", str(v)])
        result = subprocess.run(cmd, capture_output=True, text=True)
        return {"stdout": result.stdout, "returncode": result.returncode}
    
    async def rpc_execute(self, method: str, params: dict = None) -> dict:
        """JSON-RPC вызов через jarvis_server.py"""
        if self.mode == "direct":
            # Маршрутизация на основе метода
            script_map = {
                "app.launch": ("open_browser.py", {"app": "brave"}),
                "app.close": ("browser_close.py", {}),
                "system.screenshot": ("screenshot.py", {}),
                "system.sleep": ("sleep.py", {}),
                "system.notify": None,  # через API
                # ...
            }
            if method in script_map:
                script, defaults = script_map[method]
                return await self.direct_call(script, **(defaults | (params or {})))
        elif self.mode == "rpc":
            # HTTP запрос к jarvis_server.py
            pass
        elif self.mode == "ws":
            # WebSocket запрос
            pass
    
    def get_state(self, key: str = None) -> dict:
        """Получить состояние Jarvis"""
        return get_bus().get_all_state() if not key else {key: get_bus().get_state(key)}
    
    def set_state(self, key: str, value: any):
        """Установить состояние Jarvis"""
        get_bus().set_state(key, value)

Модификация Rust-core для делегирования незнакомых команд

Rust-core Jarvis — базовая логика обработки команд на Rust. Текущая проблема: падает на незнакомых командах.

Предлагаемая модификация:

// Rust core: при незнакомой команде → делегировать OpenCode
// Вместо: unknown_command → error
// Делаем: unknown_command → bridge → OpenCode → ответ

// Псевдокод Rust-core:
enum CommandResult {
    Handled(String),        // Jarvis сам обработал
    Delegated(String),      // Отправлено в OpenCode
    Error(String),          // Ошибка
}

fn process_command(text: &str) -> CommandResult {
    // 1. Проверяем локальные команды (pc-control)
    if let Some(result) = pc_control::try_execute(text) {
        return CommandResult::Handled(result);
    }
    
    // 2. Проверяем системные команды
    if let Some(result) = system::try_execute(text) {
        return CommandResult::Handled(result);
    }
    
    // 3. ⭐ Делегируем OpenCode через bridge!
    //    Bridge сам решит: LLM, интернет, код или что-то ещё
    return CommandResult::Delegated(text);
}

// Результат: Jarvis не падает на "напиши письмо"
// → делегирует OpenCode → получает ответ → TTS пользователю

Создание jarvis-integration SKILL.md

Файл: ~/.config/opencode/skills/jarvis-integration/SKILL.md

---
name: jarvis-integration
description: |-
  Интеграция OpenCode с Jarvis (голосовой ассистент).
  Позволяет OpenCode управлять компьютером через Jarvis pc-control,
  получать голосовой ввод (STT) и отвечать голосом (TTS).
  
  Используй когда нужно:
  - Выполнить команду управления ПК через голос
  - Передать запрос от Jarvis в OpenCode для LLM обработки
  - Получить состояние Jarvis (режим, VPN, аудио)
  - Отправить TTS ответ через динамики

  Примеры:
  - user: "открой браузер" → jarvis.execute("app.launch", {app: "brave", workspace: 1})
  - user: "какой режим" → jarvis.get_state("mode")
  - user: (голосом) "напиши письмо" → jarvis.stt() → OpenCode LLM → jarvis.tts()
---
