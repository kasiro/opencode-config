1. Whisper large-v3 — золотой стандарт STT

OpenAI Whisper large-v3 — самая точная модель STT на сегодняшний день.

ПараметрЗначение
Параметры1.54B (large-v3)
WER (Common Voice 15)8.2% (английский), ~12% (русский)
Поддерживаемые языки99 языков, включая русский
ФорматMultitask: transcription, translation, language detection
ЛицензияMIT
Аппаратные требования10GB+ VRAM (GPU), ~6GB RAM (CPU, медленно)

Недостатки: большой (1.5B params), медленный на CPU, требует ~10GB VRAM для реального времени. Для edge-устройств не подходит.

2. faster-whisper — оптимизированный Whisper

faster-whisper — реимплементация Whisper через CTranslate2. До 4x быстрее оригинала при сопоставимом WER.

ПараметрЗначение
МеханизмCTranslate2 (C++ inference engine)
Ускорение3-4x относительно оригинального Whisper
WER деградация< 10% relative (0.5-1% absolute)
INT8 квантизацияПоддерживается (ещё 2x ускорение)
VAD интеграцияВстроенный Silero VAD для детекции тишины
Память (large-v3, INT8)~2.5GB VRAM
Установкаpip install faster-whisper

Преимущества: значительно быстрее, почти та же точность, VAD из коробки, поддержка INT8. Рекомендуется как основной STT-движок для edge/deployment.

3. whisper.cpp — на C++

whisper.cpp — порт Whisper на C/C++ с использованием ggml. Оптимизирован для CPU, Apple Silicon (Metal), мобильных устройств.

  • Apple Metal: на M1/M2/M3 — в 2-3x быстрее CPU inference
  • ARM NEON: оптимизация для ARM процессоров
  • Отсутствие зависимостей: не требует Python, CUDA, PyTorch
  • Размер бинарника: ~30MB + модель (2-3GB)
  • Использование: ./main -m ggml-large-v3.bin -f audio.wav

Когда использовать: Apple Silicon, embedded системы, минимальные зависимости, production deployment на bare metal.

4. Vosk — лёгкая альтернатива

Vosk — лёгкий STT без GPU. Модели от 50MB до 2GB. Работает в реальном времени на Raspberry Pi.

ХарактеристикаЗначение
Размер модели (русская)~150MB (vosk-model-small-ru-0.22)
WER (русский)~15-20% (зависит от шума)
Скорость0.1x real-time на Raspberry Pi 4
Языки20+ языков
ФорматАсинхронный streaming через WebSocket
ЗависимостиМинимальные (libvosk)

Когда использовать: embedded системы, Raspberry Pi, офлайн-режим, где точность не критична.

5. openWakeWord — wake-word детекция

openWakeWord — open-source библиотека для wake-word обнаружения. Разработана ESPHome. Производит ~200MB RAM, работает на Raspberry Pi.

  • Модели: "alexa", "hey_jarvis", "okay_google" — предобученные
  • Кастомные: можно натренировать своё wake word
  • Архитектура: lightweight CNN на MFCC features
  • Точность: 95%+ recall при 1 false alarm/час
  • API: Python openwakeword.Model().predict(audio)

Совместимость: можно комбинировать с openWakeWord + RealtimeSTT для полного voice pipeline.

6. RealtimeSTT — всё в одном

RealtimeSTT — Python-пакет, объединяющий STT + wake word + VAD (Voice Activity Detection) в одной библиотеке.

from RealtimeSTT import AudioToTextRecorder

recorder = AudioToTextRecorder(
    model="large-v3",              # Whisper модель
    wake_words="Jarvis",           # Wake word
    wake_words_sensitivity=0.6,    # Чувствительность
    silero_sensitivity=0.5,        # VAD чувствительность
    post_speech_silence_duration=1.0  # Пауза после речи
)

while True:
    text = recorder.text()  # Блокирует до получения текста
    print(f"Распознано: {text}")

Плюсы: минимальный код, всё включено, настраиваемые параметры VAD и wake word.

Минусы: больше зависимостей, сложнее дебажить, менее гибкая конфигурация чем сборка отдельных компонентов.

7. Kokoro TTS — лёгкий синтез речи

Kokoro TTS — ультра-лёгкая TTS модель (82M параметров) с лицензией Apache 2.0. Оптимальна для edge-развёртывания.

ПараметрЗначение
Параметры82M (в 50x меньше Tortoise TTS)
Скорость~50x real-time (CPU), ~150x (GPU)
ЛицензияApache 2.0
Голоса8 предобученных (EN, JP, KR, ZH, FR, KO)
КачествоВысокое (MOS 3.8-4.1)
Память~300MB RAM
from kokoro import KPipeline
pipeline = KPipeline(lang_code='a')  # 'a' = American English
for voice in pipeline("Hello world", voice='af_heart'):
    audio = voice.audio  # numpy array

Недостатки: нет русского языка (пока), ограниченный набор голосов.

8. Chatterbox-Turbo TTS

Chatterbox-Turbo TTS — 350M параметров, MIT лицензия. Поддерживает emotion control, <200ms latency.

ПараметрЗначение
Параметры350M
Latency<200ms на GPU (T4)
ЛицензияMIT
Emotion Controlhappy, sad, angry, neutral, whisper
Clone Voice5-second sample для клонирования
ЯзыкиEN, ZH, JP, KR, FR, DE
Память~1.2GB RAM

Преимущество: emotion control — ключевое для создания «живого» голосового ассистента.

9. MicOracle — wake-word trigger для Claude Code

MicOracle — open-source инструмент, реализующий wake-word triggered voice input для Claude Code. Архитектура: openWakeWord → запись → STT → отправка текста в LLM.

Паттерн, используемый MicOracle:

┌────────────┐    ┌────────────┐    ┌────────────┐    ┌────────────┐
│ openWakeWord│───▶│ Audio Buffer│───▶│ faster-    │───▶│ Prompt /   │
│ (detection) │    │ (recording) │    │ whisper    │    │ Execute    │
└────────────┘    └────────────┘    └────────────┘    └────────────┘

Этот паттерн идеально подходит для Jarvis: лёгкий wake word детектор постоянно слушает микрофон, при обнаружении триггера начинает запись, после паузы отправляет на STT, результат передаётся агенту.

12. Рекомендации для Jarvis

Оптимальный пайплайн:

┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│ openWakeWord  │──▶│ faster-whisper│──▶│ LLM Agent    │──▶│ Kokoro TTS   │
│ "Jarvis"      │   │ (medium, INT8)│   │ (OpenCode)   │   │ (or Chatterbox)│
│ постоянно     │   │ ~1GB VRAM    │   │ обработка    │   │ ~300MB RAM   │
└──────────────┘   └──────────────┘   └──────────────┘   └──────────────┘
  1. Wake word: openWakeWord с кастомным "Hey Jarvis" — постоянно слушает, ~200MB RAM, 95%+ recall
  2. STT: faster-whisper medium (INT8) — хороший баланс скорости/точности, ~1GB VRAM, RTF > 3x
  3. TTS: Kokoro TTS (если достаточно английского) или Chatterbox-Turbo (если нужны эмоции и voice clone)
  4. VAD: Silero VAD (встроен в faster-whisper) — детекция начала/конца речи
  5. Audio buffer: кольцевой буфер ~3 секунды для снижения latency

Пайплайн реализуется как MCP-сервер на Python, который предоставляет Jarvis инструменты listen(), speak(), wait_for_wake_word().
