🔍 Что такое agentmemory

AgentMemory — MCP сервер на базе Node.js, работающий на localhost:3111 через systemd user service. Предоставляет 53 инструмента для управления долговременной памятью J.A.R.V.I.S. Архитектура вдохновлена Hermes Agent — системой с 4-уровневой консолидацией и Frozen Snapshot Pattern.

4-Tier Consolidation Pipeline

Данные проходят 4 уровня консолидации, каждый следующий уровень — более абстрактное и долговременное представление:

Working (сырые наблюдения от tool use)
    │ LLM-компрессия / session_summary
    ▼
Episodic (что произошло за сессию)
    │ Извлечение паттернов через reflect()
    ▼
Semantic (факты, концепты, предпочтения)
    │ Повторение и практика → consolidate()
    ▼
Procedural (уроки, навыки, how-to)
УровеньФункцияКогда запускать
Workingsave() + lesson_save()Каждое сообщение (CYCLE 1 → SAVE)
Episodicsave(type="session_summary")Конец сессии (CYCLE 3 END)
Semanticconsolidate(tier="semantic")Каждые 3-5 сессий
Proceduralconsolidate(tier="procedural")Каждые 10 сессий

❄️ Frozen Snapshot Pattern (Hermes)

Правило: Один раз загрузил → заморозил → не меняй до конца сессии. Это предотвращает инвалидацию KV-кэша модели.

При старте сессии (CYCLE 3 START):

  1. lesson_recall(query="error, pattern, preference", limit=5) — ключевые уроки
  2. memory_recall(query="slot:persona, slot:project_state", limit=3) — контекст проекта
  3. memory_profile() / memory_timeline() — профиль и недавняя история

Эти данные формируют Frozen Snapshot — они помещаются в system prompt и не меняются до конца сессии.

🚫 НЕ делай:

  • ❌ Не вызывай lesson_recall/memory_recall на каждое сообщение — это ломает KV-кэш
  • ❌ Не сохраняй одну и ту же информацию дважды
  • ❌ Не вызывай consolidate() чаще раза в сессию — это тяжелая операция

⚙️ Конфигурация

Переменные окружения (в opencode.json):

{
  "mcp": {
    "agentmemory": {
      "type": "local",
      "command": ["agentmemory", "mcp"],
      "environment": {
        "AGENTMEMORY_URL": "http://localhost:3111",
        "AGENTMEMORY_TOOLS": "jarvis"
      },
      "enabled": true
    }
  }
}

Ключевые параметры:

  • CONSOLIDATION_ENABLED=true — автоматическая консолидация
  • GRAPH_EXTRACTION_ENABLED=true — извлечение графовых связей
  • AGENTMEMORY_REFLECT=true — рефлексия через LLM
  • AGENTMEMORY_URL=http://localhost:3111 — адрес API
  • AGENTMEMORY_TOOLS=jarvis — фильтр доступных инструментов

💡 Best Practices

  • format="compact" — всегда используй для recall, чтобы экономить контекст
  • limit=5 — оптимальное количество результатов для recall/lesson_recall
  • confidence >= 0.3 — минимальный порог для lesson_recall (ниже — шум)
  • project поле — всегда указывай для scoping памяти
  • Один consolidate за сессию — не чаще, это тяжелая операция
  • Frozen Snapshot при старте — загрузи один раз, не перегружай

📌 Практические примеры

Поиск контекста:

agentmemory_memory_recall(query="архитектура плагинов", limit=5, format="compact")

Сохранение решения:

agentmemory_memory_save(type="decision", content="Выбрали SQLite для хранения конфигов", concepts="architecture, database, decision", files="opencode.json")

Извлечение урока из ошибки:

agentmemory_memory_lesson_save(confidence=0.7, tags="error", content="Не использовать glob для поиска — fd в 5-10x быстрее", context="оптимизация инструментов")

Поиск связей в графе:

agentmemory_memory_graph_query(query="MCP сервер", nodeType="architecture", maxDepth=3)

Диагностика здоровья:

agentmemory_memory_diagnose(categories="actions,leases,memories")

Что делать дальше:

agentmemory_memory_frontier(project="/home/kasiro/.config/opencode", limit=10)

Сигнал другому агенту:

agentmemory_memory_signal_send(from="jarvis", to="researcher", type="request", content="Найди документацию по DCP плагину")
